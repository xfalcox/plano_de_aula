JavaScript · clique e confirmação

Demonstração para ensaio e aula com infraestrutura. Funciona sem internet. Na prova, use os slides impressos.

Preveja o estado depois do clique. Você também pode focar o botão com Tab e ativá-lo com Enter ou Espaço.

Festa de formatura

Sua presença ainda não foi confirmada.

A confirmação é local: nenhum dado é enviado ou salvo.

const botao = document.querySelector("#participar");
const status = document.querySelector("#status");

botao.addEventListener("click", function () {
  status.textContent = "Presença confirmada!";
  botao.textContent = "Confirmado";
  botao.disabled = true;
});
