Antes e depois: o que muda?

.convite {
  background-color: #dcf6ea;
  color: #17233c;
  padding: 16px;
  border: 2px solid #1745a0;
  margin: 12px;
}

Faça uma previsão

O texto ganha espaço dentro do contorno. O convite ganha espaço fora dele.

Neste exemplo, padding e margin usam o mesmo valor nos quatro lados. px é uma unidade CSS; não precisa corresponder a um pixel físico.

Problema

O texto continua encostado na borda. Qual propriedade resolve?

Margin afasta a caixa das outras caixas. Padding afasta o conteúdo do contorno.
