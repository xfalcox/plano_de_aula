O clique dispara esta função

const botao = document.querySelector("#participar");
const status = document.querySelector("#status");

botao.addEventListener("click", function () {
  status.textContent = "Presença confirmada!";
  botao.textContent = "Confirmado";
  botao.disabled = true;
});

textContent troca o texto. disabled impede nova ativação do botão. const mantém a referência: as propriedades do elemento ainda podem mudar.

Encontre o erro

Para buscar um id, o seletor precisa de qual símbolo?

Sem #, "status" procura um elemento com esse nome. Se não existe, o resultado é null.
